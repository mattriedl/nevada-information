Nevada area codes

702 and 725 in Clark County, 775 everywhere else

702 and 725: Clark County

Area code 702 serves Las Vegas and the rest of Clark County. Area code 725 was added in 2014 as an overlay, so new numbers in the same area can get either code and every local call needs ten digits. Largest places: Las Vegas, Henderson, North Las Vegas, Enterprise, Spring Valley, Sunrise Manor, Paradise, Whitney, Winchester, Summerlin South.

775: the rest of Nevada

Area code 775 covers all 16 other county areas, from Reno and Lake Tahoe to Elko, Ely and Pahrump. Largest places: Reno, Sparks, Carson City, Pahrump, Fernley, Sun Valley, Elko, Spanish Springs, Dayton, Spring Creek.

Nevada area code questions

What are the area codes in Nevada?

Nevada has three: 702 and 725, which overlay each other in Clark County, and 775 for the rest of the state.

Do I need to dial 10 digits in Las Vegas?

Yes. Because 702 and 725 share the same area, local calls in Clark County need the area code plus the seven-digit number.

Which area code is Reno?

Reno, Sparks, Carson City, Elko, Pahrump and every other place outside Clark County use 775.

When did 775 start?

Area code 775 was split from 702 in 1998. Before that, 702 covered all of Nevada.
